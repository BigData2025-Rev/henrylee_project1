# henrylee-project1
Bookstore app that has the following features: 

- sign up for new account 
- log into either user or administrator account 

- User Page:
    1. Buy books:
        1. add a book to cart 
        2. checkout order 
        0. exit to menu 
    2. View Past orders:
        shows order list
        1. view one order's details 
        0. exit to menu 
    0. Exit:
        logout from account 

- Administrator Page:
    1. Update Book Catalog: 
        1. add a new book 
        2. delete a book
        3. update book price 
        4. update book quantity 
        0. exit to menu 
    2. Manage Users:
        1. add a new user
        2. remove a user
        3. grant admin access to a user
        0. exit to menu
    3. Show All Past Orders:
        1. view one order's details
        0. exit to menu
    0. Exit:
        logout from account
